Detailed Description

Manages keyboard and mouse input state and event callbacks.

InputManager tracks pressed keyboard keys and mouse buttons, maintains the current mouse state, and allows callbacks to be registered for specific input events.

Registered callbacks can be removed using their associated BindingID.
