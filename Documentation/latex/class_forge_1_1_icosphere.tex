\doxysubsection{Detailed Description}
Represents a procedurally generated icosphere mesh. 

Extends \doxylink{class_forge_1_1_mesh}{Mesh} to generate a spherical geometry using an icosahedron as its base geometry. Supports configurable radius, subdivision levels, inverted geometry, and spherical UV coordinate generation.
