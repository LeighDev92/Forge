\doxysubsection{Detailed Description}
Manages keyboard and mouse input state and event callbacks. 

\doxylink{class_forge_1_1_input_manager}{Input\+Manager} tracks pressed keyboard keys and mouse buttons, maintains the current mouse state, and allows callbacks to be registered for specific input events.

Registered callbacks can be removed using their associated Binding\+ID.
