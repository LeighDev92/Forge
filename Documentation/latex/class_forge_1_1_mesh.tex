\doxysubsection{Detailed Description}
Represents a renderable 3D mesh. 

Stores mesh geometry, transformation data, material properties, and Direct3D 11 vertex and index buffers.

Supports loading mesh geometry from OBJ files, modifying transformations, configuring materials, and providing geometry and buffer data to the graphics renderer.
