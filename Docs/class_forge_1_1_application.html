Forge
Forge is a custom 3D graphics engine developed in C++ using Microsoft's Direct3D 11 graphics API. Designed as a modular and extensible foundation for real-time graphics applications, Forge provides a collection of core engine systems responsible for graphics rendering, resource management, input processing, and application lifecycle management.

Detailed Description

Serves as the primary entry point and central coordinator of a Forge application.

Responsible for managing the application lifecycle, initializing core engine systems, coordinating runtime operations, and maintaining references to essential engine components and resources.

◆ Run()

virtual int Forge::Application::Run ( )
virtual

Executes the main application loop.

Processes pending Windows messages, handles accelerator keys, and executes the application's frame lifecycle while the application is running.

Each frame calculates the elapsed time since the previous frame and calls BeginFrame() followed by EndFrame().

The loop terminates when a WM_QUIT message is received.

Returns
The exit code supplied by the WM_QUIT message.
